🎮 Pruebas (Playtesting)

Detección de fallos y pruebas de usuario

Durante el desarrollo tuvimos problemas con el sistema de inventario y el guardado de objetos. Se realizaron varias pruebas hasta conseguir que los elementos se mantuvieran correctamente al reiniciar niveles o cambiar de escena.

🔧 Correcciones

❌ Problema Identificado ✅ Solución Aplicada
El personaje atravesaba ciertas paredes al colisionar. Se modificaron y reajustaron los componentes Collider2D.
Los objetos desaparecían al cargar una partida guardada. Se reestructuró la persistencia de datos mediante guardado de IDs en JSON.
errores en las animaciones del jugador/tamaño de sprites y tilemaps se comenzo nuevamente todo el proyecto sin usar IA para crear la parte visual
